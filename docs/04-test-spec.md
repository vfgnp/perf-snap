## 1. テストの種類

| 種類 | 実行方法 | 権限 | 内容 |
|---|---|---|---|
| 自動テスト | `dotnet test PerfSnap.slnx` | 不要 | wpr / logman を模擬に置き換えて、処理の流れ・判定・ファイル操作を確認する |
| 結合テスト | `scripts\verify-integration.ps1` | **管理者** | 本物の wpr / logman と exe を動かす |
| 手動テスト | §4 のチェックリスト | **管理者** | 画面の操作など、自動化しにくいもの |

## 2. 自動テスト（38 件）

| 対象 | 確認すること | 対応する要件 |
|---|---|---|
| StallJudge | しきい値の判定、スリープ復帰（60 秒以上）の除外、電源変化の前後 10 秒の除外 | F-15 |
| AutoSaveGate | 自動保存の間隔、1 日の上限、日付が変わったら数え直し | F-15 |
| HotkeyParser | ホットキー表記の解釈。修飾キーなしは不可 | F-04 |
| WprRecorder / CounterRecorder | コマンドの引数（`-instancename` が最後、logman の間隔の書式） | F-10〜F-12 |
| AutoStartManager | タスク登録 XML の電源・時間制限の解除、特権、XML のエスケープ | F-06 |
| SettingsStore | 既定値の作成、読み戻し、壊れたファイルの退避、範囲外の値の修正、ネットワークパスの拒否 | F-30 |
| CaptureFolder | フォルダ名の規約と重複時の番号、自分の meta の判定 | F-20 |
| RetentionManager | 古い順の削除、**自分のフォルダ以外・counters・保存直後のフォルダは消さない** | F-21, N-21 |
| CaptureController | 起動時の後片付け、保存の流れと監視の再開、自動保存の待ちと歯止め、保存失敗時の復旧、空き容量不足、時間指定の記録、終了処理 | F-10〜F-15, F-32 |

## 3. 結合テスト（scripts\verify-integration.ps1）

| ID | 確認すること | 合格の基準 | 対応する要件 |
|---|---|---|---|
| IT-B | 各プロファイルでメモリーモード・ファイルモードの開始、目印、保存ができる | 終了コード 0、.etl ができる | F-10, F-11, F-13 |
| IT-C | 120 秒記録した後、何秒分のデータが残っているか | 実測値を記録する（目標：60 秒以上） | G2 |
| IT-D | フライトレコーダー中の PC 全体の CPU 使用率の増加 | 実測値を記録する（README に明記） | N-03 |
| IT-E | logman で英語名のカウンターを集められる。記録中の .blg を読める | 作成・開始が成功、.blg ができる | F-12, F-22 |
| IT-F1 | exe が管理者権限で起動して常駐する | 20 秒後もプロセスが動いている | F-01 |
| IT-F2 | 待機中のツールの CPU・メモリ | CPU 平均 0.1% 未満、メモリ 50 MB 以下 | N-01, N-02 |
| IT-F3 | ホットキーで保存できる | 保存フォルダに trace.etl・sysinfo.txt・meta.json（result=ok）ができ、その後 wpr が記録を再開している | F-04, F-10, F-23 |
| IT-F4 | 強制終了後に起動し直すと、残った記録を片付けて動き出す | 再起動後にプロセスが動いている。ログに後片付けの記録がある | F-32, N-10 |

## 4. 手動テスト（チェックリスト）

| ID | 操作 | 期待する結果 |
|---|---|---|
| MT-01 | exe をダブルクリックで起動する | UAC の確認が出る。トレイに緑のアイコン（波形）が出る |
| MT-02 | もう一度 exe を起動する | 「すでに起動しています」と表示され、2 つ目は起動しない |
| MT-03 | アイコンを右クリックする | メニューが出る。見出しに「監視中」と出る |
| MT-04 | Ctrl+Alt+Shift+P を押す | アイコンが黄色（矢印）になり、右下にメモ欄が出る。数十秒で「保存しました」の通知が出る |
| MT-05 | 通知をクリックする | 保存フォルダが開く |
| MT-06 | メモ欄に入力して「残す」 | 保存フォルダに memo.txt ができる |
| MT-07 | メニュー「時間を指定して記録」→「30 秒」 | アイコンが赤（点）になり、ツールチップに残り秒数が出る。30 秒後に保存される |
| MT-08 | メニュー「監視」のチェックを外す | アイコンが灰色（丸）になる。ホットキーを押すと「監視が止まっています」と通知される |
| MT-09 | メニュー「プロファイル」→「詳細」 | チェックが移る。監視が新しいプロファイルで再開される |
| MT-10 | 設定画面でホットキーを Ctrl+Shift+F9 に変えて保存 | 新しいキーで保存できる。古いキーは反応しない |
| MT-11 | 設定画面で「ログオン時に自動で起動する」をオンにして保存し、サインアウト → サインイン | UAC の確認なしで、約 30 秒後にトレイアイコンが出る |
| MT-12 | 自動起動をオフにして保存 | タスク スケジューラから PerfSnap のタスクが消える |
| MT-13 | 保存した trace.etl を Windows Performance Analyzer で開く | 開ける。目印（PerfSnap_hotkey など）が見える |
| MT-14 | counters\PerfSnap_Light.blg をパフォーマンスモニターで開く | 開ける。グラフが出る |
| MT-15 | メニュー「終了」 | アイコンが消える。`wpr -status -instancename PerfSnap` で記録が残っていない |

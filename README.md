# PerfSnap

Windows 11 で「キー入力が 2 秒ほど遅れる」「画面の更新が止まる」といった、**不定期に数秒だけ起きる重さ**を調べるためのタスクトレイ常駐ツールです。

事象に気付いたらホットキーを押すだけで、**気付く前の数分間を含む**調査用データ（ETW トレースとパフォーマンスカウンター）を保存します。ツール自体は待機中ほとんど CPU を使いません。

> 記録には Windows 標準の `wpr.exe`（Windows Performance Recorder）と `logman.exe` だけを使います。追加のドライバーは入れません。

---

## 主な機能

| 機能 | 内容 |
|---|---|
| フライトレコーダー | メモリ上で直近のデータを記録し続け、保存した瞬間に**それまでの分**をファイルに書き出す |
| ホットキー保存 | 既定は **Ctrl+Alt+Shift+P**。トレイアイコンのダブルクリックでも保存できる |
| 自動検知 | PC 全体が 1.5 秒以上止まったとき／前面のアプリが応答しなくなったときに自動で保存する（10 分に 1 回まで、1 日 20 回まで） |
| 時間指定の記録 | 30 / 60 / 120 / 300 秒だけファイルに記録する |
| 軽量監視 | CPU・ディスク・メモリ・DPC/割り込み・プロセス別の負荷を 15 秒間隔で記録し、保存のたびに一緒に残す |
| メモ | 保存時に「何が起きたか」を一言残せる |
| 容量管理 | 保存先が 10 GB を超えたら、PerfSnap が作った古いデータから自動で削除する |

## 動作環境

- Windows 11（x64）
- **管理者権限**（wpr / logman の操作に必要）
- .NET のインストールは不要（exe に含まれています）

## 使い方

1. [Releases](../../releases) から `PerfSnap.exe` をダウンロードし、任意のフォルダ（例：`C:\Tools\PerfSnap\`）に置きます。
2. ダブルクリックで起動します。UAC の確認で「はい」を選ぶと、タスクトレイに**緑のアイコン**が出ます（監視中）。
3. 重くなったら **Ctrl+Alt+Shift+P** を押します。アイコンが黄色になり、30〜40 秒ほどで「保存しました」と通知されます。通知をクリックすると保存フォルダが開きます。
4. 毎回 UAC の確認を出さずに使いたい場合は、右クリックメニューの「設定...」→「全般」→「ログオン時に自動で起動する」をオンにします（タスク スケジューラに登録されます）。

### アイコンの意味

| アイコン | 状態 |
|---|---|
| 灰色・丸 | 待機中（監視していない） |
| 緑・波形 | 監視中（直近のデータを保持） |
| 赤・点 | 時間指定の記録中 |
| 黄・矢印 | 保存中 |

### 保存されるもの

保存先（既定：`%LOCALAPPDATA%\PerfSnap\captures`）に、保存 1 回ごとのフォルダができます。

```
20261123_143015_hotkey\
├── trace.etl      ETW トレース → Windows Performance Analyzer で開く
├── counters.blg   軽量監視のカウンター → パフォーマンスモニターで開く
├── sysinfo.txt    PC の情報とプロセス一覧
├── memo.txt       メモ（入力した場合）
└── meta.json      保存のきっかけ、自動検知の遅れの大きさなど
```

`trace.etl` の分析には **Windows Performance Analyzer（WPA）** を使います（Microsoft Store から無料で入手できます）。トレースには `PerfSnap_hotkey` などの目印が入っているので、保存した瞬間にすぐ移動できます。セキュリティ製品の影響を調べるときは、**Mini-Filter Delays**（ファイル検査にかかった時間）や、CPU Usage (Precise) の待ち時間を見るのが手がかりになります。

## 負荷の目安

この PC での実測値です（Windows 11、論理 8 コア、メモリ 7.7 GB）。詳しくは [テスト結果報告書](docs/05-test-report.md) を参照してください。

| 項目 | 実測値 |
|---|---|
| 待機中のツールの CPU | 約 0.02% |
| 待機中のツールのメモリ（タスク マネージャー表示） | 約 4 MB |
| 監視中に Windows が使う記録用メモリ | 256 MB（設定で 64〜2048 MB に変更可） |
| 監視中の PC 全体の CPU の増加 | 約 1〜2 ポイント |
| 保存にかかる時間 | 約 30〜40 秒（この間は記録が途切れます） |
| 1 回の保存のサイズ | 約 20〜45 MB（圧縮後） |

## 注意事項

- **署名なしの exe です。** Windows の「スマート アプリ コントロール」が有効な PC では、起動をブロックされることがあります。組織で管理されている PC では、セキュリティ製品にブロックされる場合があるので、**事前に管理者（IT 部門など）に確認**してください。
- **保存したデータには、PC 内のファイル名・プロセス名などが含まれます。** 社外に送ったり、Git に入れたりしないでください。
- 他のツールが同時に ETW のカーネル記録を使っていると、監視を開始できないことがあります。その場合は通知とログで知らせます。
- 標準ユーザーが**別の管理者アカウント**で UAC を通した場合、設定や保存先はその管理者アカウント側（`%APPDATA%`、`%LOCALAPPDATA%`）になります。
- 待機中でも、軽量監視（logman）は Windows のサービスとして動き続けます。止めたい場合は、メニューの「軽量監視」をオフにしてください。

## アンインストール

1. 設定画面で「ログオン時に自動で起動する」をオフにする
2. メニューの「終了」で終了する
3. exe と、`%APPDATA%\PerfSnap`、`%LOCALAPPDATA%\PerfSnap` のフォルダを削除する

## 設定ファイル

`%APPDATA%\PerfSnap\settings.json`。画面から変更できない項目もここで変えられます。項目と既定値は [詳細設計書 §7](docs/03-detailed-design.md) を参照してください。

## 開発

| 項目 | 内容 |
|---|---|
| 言語・環境 | C# / .NET 10 / WinForms |
| ビルド | `dotnet build PerfSnap.slnx` |
| 自動テスト | `dotnet test PerfSnap.slnx`（管理者権限は不要） |
| 結合テスト | 管理者の PowerShell で `scripts\verify-integration.ps1 -OutDir <出力先> -Exe publish\PerfSnap.exe` |
| 配布用 exe | `dotnet publish src/PerfSnap -c Release -o publish` |
| 同梱プロファイルの再生成 | `scripts\build-wprp.ps1`（Windows の更新で組み込みプロファイルが変わったとき） |

リリースは、`v` で始まるタグを push すると GitHub Actions が exe を作って Releases に添付します（`-rc1` などを含むタグはプレリリース）。
